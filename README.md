## ⚛️ Quantum Learning Roadmap

| Area | What I'm learning |
|---|---|
| **Foundations** | Linear algebra, complex numbers, probability, qubits, superposition, the Bloch sphere |
| **Gates & Circuits** | Pauli gates (X, Y, Z), Hadamard, phase, CNOT, Toffoli, measurement |
| **Entanglement** | Bell states, CHSH inequality, quantum teleportation, superdense coding |
| **Algorithms** | Deutsch-Jozsa, Bernstein-Vazirani, Grover's search, Shor's algorithm, quantum Fourier transform, quantum phase estimation |
| **Variational & Hybrid** | VQE, QAOA, variational circuits, quantum machine learning |
| **Cryptography** | BB84 key distribution, post-quantum cryptography |
| **Physics** | Schrödinger equation, tunneling, quantum harmonic oscillator, density matrices |
| **Noise & Hardware** | Decoherence, error mitigation, error correction basics, running on real IBM Quantum devices |
| **Quantum Finance** | Quantum amplitude estimation, option pricing vs classical Monte Carlo, portfolio optimisation |
